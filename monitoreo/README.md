# Sistema de Monitoreo de Sucursales

Aplicación desarrollada en **C# y .NET Framework 4.8** para supervisar sucursales, detectar incidencias operativas y automatizar procesos empresariales.

## Características

- Monitoreo periódico de sucursales y transacciones pendientes.
- Consultas y ejecución de procedimientos almacenados en SQL Server.
- Integración con SAP HANA para sincronización de existencias.
- Registro de alertas e incidencias operativas.
- Automatización de verificaciones y acciones de recuperación.
- Interfaz gráfica desarrollada con Windows Forms y DevExpress.
- Registro de eventos y errores mediante archivos de log.
- Configuración de intervalos y parámetros de monitoreo.

## Tecnologías

- C#
- .NET Framework 4.8
- Windows Forms
- DevExpress
- SQL Server
- ADO.NET
- SAP HANA

## Objetivo

Centralizar la supervisión de procesos operativos distribuidos entre distintas sucursales, facilitar el diagnóstico de incidencias y reducir las tareas manuales mediante automatización e integración de sistemas.

## Configuración

Para ejecutar el proyecto se requiere configurar las conexiones a las bases de datos y disponer de las dependencias necesarias.

**Seguridad:** no incluyas credenciales, direcciones de servidores internos ni información confidencial de empresas en este repositorio.
